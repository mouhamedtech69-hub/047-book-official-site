موقع كتاب 0.47 — محمد نجاعي
================================

محتويات المشروع
- index.html: الصفحة الرئيسية والنوافذ المنبثقة.
- styles.css: التصميم والحركة والتجاوب مع الهاتف.
- script.js: القوائم والرسائل والتحقق من رمز الهدية.
- assets/: أيقونات PNG أصلية مرسومة خصيصاً للموقع.
- netlify/functions/redeem-gift.mjs: التحقق من رموز الهدايا على الخادم.

روابط النسخ المضافة
- النسخة العامة (فصلان): Google Drive preview.
- النسخة الكاملة المدفوعة: https://payhip.com/b/meKvR بسعر $2.99.
- نسخة الهدية: لا تُفتح إلا بعد ضبط متغيرات البيئة في Netlify.

قبل النشر
1) ارفع مجلد المشروع إلى GitHub أو اسحبه إلى Netlify Drop.
2) لأن بوابة الرموز تعتمد على Netlify Functions، الأفضل ربط المشروع بمستودع Git أو نشره عبر Netlify CLI، وليس استضافة HTML ثابتة فقط.
3) في Netlify افتح: Site configuration > Environment variables.
4) أضف المتغير GIFT_PDF_URL وضع فيه رابط النسخة الكاملة المخصصة للأصدقاء:
   https://drive.google.com/file/d/152lnuev-qnb8hJyDiUkO_Lx98s7PnH0w/view?usp=sharing
5) أضف المتغير GIFT_CODES وضع فيه الرموز السرية مفصولة بفواصل، مثال شكلي فقط:
   047-MJ-A8K2,047-MJ-X9P4,047-MJ-B7L5
   غيّر هذه الأمثلة إلى رموزك الفعلية، ولا تضعها في index.html أو script.js.
6) أعد نشر الموقع بعد إضافة المتغيرات.
7) تأكد أن ملف Google Drive مضبوط على Anyone with the link / Viewer حتى يستطيع المستلم فتحه بعد قبول الرمز.

اختبار محلي
- ثبّت Node.js ثم نفّذ: npm install
- ثبّت Netlify CLI إن لم يكن مثبتاً: npm install -g netlify-cli
- شغّل: netlify dev
- الاختبار المحلي للدالة يحتاج ضبط متغيرات البيئة في Netlify CLI أو ملف .env محلي غير مرفوع إلى Git.

تنبيه مهم
- لا تضع رابط نسخة الأصدقاء الكامل داخل HTML أو JavaScript.
- الرموز تُستهلك مرة واحدة عند نجاح أول تحقق، ويُحفظ الاستعمال في Netlify Blobs.
- بعد فتح رابط Google Drive يستطيع المستلم نظرياً مشاركة الملف نفسه؛ هذه بوابة وصول بالرمز وليست حماية DRM تمنع نسخ PDF.
- لم أتمكن من فحص محتوى ملفات Google Drive من داخل هذه الجلسة؛ الروابط أُدرجت كما أرسلتها.
- صور الغلاف والتصاميم الترويجية مربوطة حالياً بروابط Top4Top التي زودتني بها. الأفضل تنزيلها ووضعها داخل assets ثم تغيير src إلى أسماء الملفات المحلية إذا لم تظهر بسبب منع hotlink.
- لم تتم إضافة إعلانات Adsterra لأن كود الإعلان لم يُرسل بعد. مكان الإعلان يمكن إضافته لاحقاً دون إزعاج تجربة القراءة.
